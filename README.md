# 💗 Happy 28th Birthday, Himani

A personalized birthday surprise website made for Himani — born **20 August 1998**.

## What's customized

- Himani's name and 28th birthday
- The affectionate "Chudail" nickname
- A personal best-friend letter
- The three supplied photos
- A countdown to 20 August
- Scroll reveal animations
- A celebration/confetti interaction
- Mobile-friendly responsive layout
- No build step required

## Run locally

Open `index.html` in a browser.

For GitHub Pages / Netlify / Vercel, upload the project as-is.

## Easy ways to make it even more personal

1. Add 10–20 more photos to the memory gallery.
2. Add a favorite song with a play/pause control.
3. Add a "Our funniest moments" timeline with real stories.
4. Add voice notes from friends.
5. Add a password/reveal screen so the surprise feels private.
6. Add a final "Make a wish" candle animation.


## New birthday-surprise features

### 🔐 Password screen
The site now opens with a private birthday gate. Accepted passwords are:
- `chudail`
- `himani`
- `birthday`

For a truly private version, change these values in `script.js`.

### 🕯️ Blow out the candle
The birthday section has an animated cake and candle. The candle can be extinguished with the button, or with optional microphone input when the site is served from a browser context that permits microphone access.


### 🐻 New password → bear video → website flow

The experience now works in this order:

**Password → cute animated bear video → candle/birthday website**

The bear video is bundled locally as `media/cute-bear-birthday.mp4`, so there is no external video dependency. The user can also skip the animation.
